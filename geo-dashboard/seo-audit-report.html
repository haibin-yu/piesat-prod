一、结论

单篇文章页的 SEO 元素（title / description / keywords / JSON-LD / H1）基本完整保留，但站点级技术配置存在 5 个问题，其中 3 个致命。这是导致「官网博客在百度搜不到、只有百家号 / 头条号排在前列」的技术根因——不是内容不行，是搜索引擎「找不到、抓不全、信不过」官网。

三、5 个问题（按优先级）

P0 · 致命

sitemap.xml 未收录博客文章

现象

https://www.piesat.cn/sitemap.xml 共 1058 个 URL，没有一条是 blog / bloginfo 条目。

影响

搜索引擎无法通过 sitemap 发现博客文章，只能靠爬虫偶然爬到；而官网博客路径深、权重低，爬虫很难摸到，导致文章长期不被收录。

修复

把 6 篇博客 URL 加进 sitemap.xml（或单独生成博客 sitemap，再在 sitemap.xml 里引用）。

P0 · 致命

robots.txt 屏蔽了所有文章图片

现象

robots.txt 含以下规则，而文章图片全部位于 /uploads/ 目录：

Disallow: /uploads/
Disallow: *.jpg$
Disallow: *.png$
Disallow: *.gif$
影响

文章配图完全无法被搜索引擎抓取，图片 SEO 全废；AI 引擎也抓不到图片信息。

修复

放开 /uploads/ 下的图片抓取（去掉 Disallow: /uploads/ 及图片扩展名规则），或将博客图片迁移到未被屏蔽的目录。

P1 · 重要

canonical 缺失 + 结构化数据 URL 错误

现象
  1. 单篇文章页没有 <link rel="canonical">；
  2. JSON-LD 中 mainEntityOfPage.@id 写的是 https://www.piesat.cn/blog/sar-radar-principle（不存在的路径），而文章真实 URL 是 https://www.piesat.cn/website/cn/pages/blog/bloginfo/2581.html。
影响

搜索引擎收到一个错误 / 缺失的规范地址信号，无法正确识别页面的权威 URL。

修复

单篇加 canonical 指向真实 URL；JSON-LD 的 mainEntityOfPage.@id 与 image（当前为相对路径 /uploads/...）改为绝对 URL。

P1 · 重要

datePublished 日期错误

现象

JSON-LD 的 datePublished / dateModified 为 2026-07-15，与文章实际发布（2026-08）不符。

影响

时效性信号错乱。

修复

改为真实发布日期。

P2 · 建议

博客列表页 SEO 缺失

现象

<title> 仅「技术博客」，无 description、keywords、canonical、JSON-LD。

影响

博客列表页是博客的入口页，SEO 缺失影响整站权重传递与收录。

修复

title 改为「技术博客 - 航天宏图信息技术股份有限公司」等含品牌词；补 description 与结构化数据（Blog / ItemList）。

六、背景说明（为什么官网排不过百家号 / 头条号）

  1. 平台权重：百家号（baijiahao.baidu.com）是百度自家平台，天然享受最高权重倾斜；头条号同理。独立域名要超它，本质上是在对抗平台自己的生态。
  2. 技术配置缺口：本报告列出的 5 个问题，让官网博客「该被收录的没进 sitemap、该被抓的图片被 robots 挡住、该明确的规范地址是错的」。
  3. 时间积累：文章 8 月刚上线，域名权重、外链、被引用量需要时间沉淀。

修复上述 P0/P1 问题后，官网博客才有进入百度首页（前 10）的技术基础；目标应定为「官网进首页、与百家号并存」，而非「盖过百家号排第一」。
