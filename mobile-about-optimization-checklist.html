逐项改法

P0

补 viewport（首页 + 关于页 + 全站模板）

现状：首页与关于页的 <head> 里均无 viewport，手机浏览器按桌面宽度（≈980px）渲染再整体缩小，首屏文字偏小、需要双击放大——直接对应「移动端 45 词、展现 109、点击 1、点击率 0.92%」。

改法：在每个页面模板的 <meta charset="UTF-8"> 之后加一行：

<meta name="viewport" content="width=device-width, initial-scale=1.0">

官网已用 Bootstrap 响应式类（d-lg-none 等），但没有 viewport 时这些媒体查询在移动端不会按预期生效。补上 viewport 后，既有的响应式 banner 图（banner1@750.png 等）才会真正按移动端宽度起效。

P0

关于页正文直出

现状：about-us.html 仅 4KB / 97 行，5 个 tab（公司介绍 / 组织架构 / 典型客户&合作伙伴 / 联系我们 / 业务合作）的正文全部通过 loadPage() 异步加载自 profile.html / organization.html / partner.html / contact.html / cooperation.html，初始 HTML 里没有正文文字。

影响：AI 引擎（豆包 / DeepSeek 等联网抓取）通常只取原始 HTML，异步注入的正文几乎拿不到；百度爬虫虽能渲染 JS，但异步内容不保证稳定抓取。导致关于页在搜索里近乎隐形。

改法（按站点技术栈二选一）：

方案 A（最简单，推荐）：把 5 个片段文件的内容直接内联进 about-us.html 对应 tab，删除 loadPage() 调用，爬虫即可抓取全部正文。

方案 B（SSI）：若 nginx 支持 SSI，用服务端包含替代：

<!--#include virtual="/website/cn/pages/about/profile.html" -->

首页与关于页的 header / footer 也是 loadPage() 加载的，影响相对小，可一并直出，或暂保留。

P1

title 优化

首页现状（约 50 字符，移动端必被截断）：

航天宏图 | 卫星运营与应用服务提供商 · 女娲星座SAR卫星 + PIE-Engine遥感云平台

首页改法（精简到 20 字以内，品牌词 + 核心定位）：

航天宏图_卫星运营与应用服务提供商

关于页现状：<title>关于我们</title>（无品牌词，浪费品牌权重）。

关于页改法：

关于航天宏图_公司简介
P1

description 去重

首页 <head> 里出现了两条完全相同的 <meta name="description">，删掉重复的一条，只保留一条。

P1

补企业性质表述

现状：公司介绍正文（profile.html）有「科创板首批上市企业」「股票代码 688066」「成立于 2008 年」，但通篇没有「国企 / 央企 / 国有 / 民营」等企业性质判断词。用户搜「航天宏图是国企还是央企」时，内容本身答不上来。

改法：在 profile.html「航天宏图简介」首段补一句明确性质，示例：

航天宏图信息技术股份有限公司是科创板上市企业，非国有企业，由创始团队创办。

具体性质表述以公司法务口径为准，但必须出现「国有 / 民营」的明确判断词，才能承接「是国企还是央企」的搜索意图。

P2

补 H1

首页：在首屏品牌区域加唯一 <h1>航天宏图</h1>（可视觉隐藏，但保证存在且唯一）。

关于页：加 <h1>关于航天宏图</h1>。

P2

补 canonical

首页：

<link rel="canonical" href="https://www.piesat.cn/">

关于页：

<link rel="canonical" href="https://www.piesat.cn/website/cn/pages/about/about-us.html">
P2

启用 gzip（nginx）

现状：响应头无 Content-Encoding: gzip，HTML 原样传输。

gzip on;
gzip_min_length 1024;
gzip_types text/plain text/css application/javascript application/json image/svg+xml;
P2

静态资源缓存（nginx）

现状：响应头无 Cache-Control，重复访问不缓存。

location ~* \.(css|js|png|jpg|jpeg|gif|svg|ico|woff2?)$ {
    expires 30d;
    add_header Cache-Control "public, max-age=2592000";
}
